# Arquivos do primeiro protótipo

Exemplos gerados com a versão 0.1.0 do Estrutura, preservados aqui para acesso pelo GitHub.

- [Interface em tela de computador](prototipo-desktop.png)
- [Interface em tela de celular](prototipo-mobile.png)
- [Relatório de exemplo em PDF](relatorio-exemplo.pdf)
- [Dados do exemplo em JSON](../../examples/viga-distribuida.json)
- [Instruções para executar o código](../../README.md)

O exemplo representa uma viga biapoiada de 6 m, seção de 20 × 50 cm, módulo de elasticidade de 30 GPa e carga distribuída de 12 kN/m, sem carga pontual. Resultados: 36 kN em cada apoio, momento máximo de 54 kN·m e flecha máxima de 3,24 mm.

Estas imagens e este PDF são registros do primeiro protótipo. Para gerar novos resultados, execute o aplicativo ou o teste opcional de navegador descrito no README principal. O módulo realiza análise elástica; não inclui dimensionamento normativo ou armaduras.
